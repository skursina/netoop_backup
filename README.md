# Резервное копирование картинок с котиками на Яндекс.Диск

## Описание проекта
Программа для массового резервного копирования картинок с сайта [cataas.com](https://cataas.com) в облачное хранилище Яндекс.Диск.
Программа находит **ВСЕ** картинки и загружает их "по воздуху" (без сохранения локально).

## Функциональность
- Указание количества загружаемых картинок через API cataas.com
- Получение списка ID всех картинок для загрузки
- Загрузка каждой картинки по ID
- Добавление надписи на все загружаемые картинки
- Создание папки на Яндекс.Диск (название папки = номер группы)
- Загрузка всех найденных картинок на Яндекс.Диск
- Сохранение подробного JSON-отчета с информацией о всех загруженных файлах
- Детальное логирование всех действий в файл с прогресс-барами в консоли

## Требования
- Python 3.8+
- Аккаунт Яндекс.Диск
- Токен для Яндекс.Диск API (получить на [Полигоне](https://yandex.ru/dev/disk/polygon/))
